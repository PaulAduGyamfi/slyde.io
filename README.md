# slyde.io
<h4>https://slydeio.herokuapp.com/</h4>

A full stack social media application built to let users easily connect with friends, using the MERN stack.

## What This Project Accomplished

- Built a complete social networking application from the ground up, covering both the client-facing UI and the backend API
- Designed and implemented a RESTful API on a Node.js server to handle core app functionality
- Implemented JWT-based authentication, allowing users to securely sign up, log in, and maintain sessions
- Structured the app around the MERN stack (MongoDB, Express, React, Node.js), handling data modeling, routing, and state management end-to-end

## Technologies Used

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Auth:** JSON Web Tokens (JWT)

## What I Learned

Building slyde.io end-to-end meant owning decisions across the whole stack — from schema design in MongoDB, to securing routes with JWT middleware, to managing state and API calls on the frontend. It was a hands-on introduction to how the pieces of a production-style web app fit together beyond a single tutorial or course assignment.
